# 🚀 EmpreendeJovem — Jogos de Empreendedorismo BNCC

Plataforma de jogos educativos sobre empreendedorismo para o **Ensino Fundamental II** (6º ao 9º ano), desenvolvida com base nas competências gerais da [Base Nacional Comum Curricular (BNCC)](https://base.bncc.gov.br/).

## 🎯 Objetivo

Desenvolver competências empreendedoras nos estudantes de forma lúdica e interativa, conectando conceitos de negócios, finanças, inovação e liderança ao cotidiano escolar.

## 🎮 Jogos disponíveis

| Jogo | Área | Competências BNCC |
|------|------|-------------------|
| 🚀 Missão Empresarial | Negócios | 2, 9 |
| 💰 Banco do Futuro | Finanças | 1, 5 |
| 💡 IdeaLab | Inovação | 2, 4 |
| 👑 CEO por um Dia | Liderança | 8, 9 |
| 🛒 Mercado Virtual | Negócios | 1, 7 |
| 🌍 EcoNegócio | Inovação | 7, 10 |

## 🏫 Competências BNCC contempladas

- **Competência 1** — Conhecimento
- **Competência 2** — Pensamento científico, crítico e criativo
- **Competência 4** — Comunicação
- **Competência 5** — Cultura digital
- **Competência 7** — Argumentação / Sustentabilidade
- **Competência 8** — Autoconhecimento e autocuidado
- **Competência 9** — Empatia e cooperação
- **Competência 10** — Responsabilidade e cidadania

## 🛠️ Tecnologias

- HTML5
- [Tailwind CSS](https://tailwindcss.com/) (CDN)
- JavaScript Vanilla
- GitHub Pages (hospedagem)

## 🚀 Como usar

1. Clone o repositório
2. Abra `index.html` no navegador
3. Nenhuma dependência ou build necessário!

Ou acesse diretamente via GitHub Pages:
`https://financeiroetica01-art.github.io/jogos-empreendedorismo-bncc/`

## 👩‍🏫 Para Professores
